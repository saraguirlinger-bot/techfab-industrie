Mission 09 · Forecast & atterrissage
Les données réelles S1 confirment les dérives. La direction attend un forecast révisé et un plan d'action concret pour le S2. Vous avez 48 heures.
01 · Contexte
Où en êtes-vous — Le forecast, outil de pilotage
📌
Mission 08 : trois écarts défavorables identifiés : CA −9,5 %, inflation matières +8,1 %, énergie +15 %. La marge brute S1 est de 191 K€ au lieu de 282 K€ prévu.

Le forecast n'est pas un aveu d'échec — c'est un outil de gestion. Il intègre les données réelles S1 + les hypothèses révisées S2 pour donner une image fiable de l'atterrissage annuel. Un forecast bien construit permet de prendre des décisions correctives à temps, pas après la clôture.

02 · Objectifs
Ce que vous devez analyser et calculer
🎯
Construire le forecast annuel — Réel S1 + Prévisions S2 révisées = Forecast N. Recalculer CA, coûts, marge, RN.
🔧
Définir le plan d'action S2 — Pour chaque écart : action corrective, responsable, objectif chiffré.
📊
Chiffrer l'atterrissage — Forecast RN : sera-t-il positif ? À quel niveau face au budget initial (85 K€) ?
💡
Identifier le levier trésorerie prioritaire — Renégocier les délais clients (75 j → 45 j) = gain de BFR immédiat.
03 · Excel
Votre travail dans le fichier Excel
📗
Ouvrez l'onglet 09-Forecast
  1. Intégrez les données réelles S1 dans le tableau de forecast : CA 573 K€, matières +8,1 %, énergie +15 %.
  2. Révisez les hypothèses S2 : CA S2 cible (plan d'action), inflation matières maintenue à +8 %, énergie +12 %.
  3. Calculez le CA forecast annuel : CA réel S1 + CA prév. S2 révisé.
  4. Calculez le coût de production forecast avec les nouvelles hypothèses d'inflation.
  5. Calculez le RN forecast pour les 3 scénarios révisés (Prudent/Réaliste/Optimiste révisés).
  6. Rédigez le plan d'action S2 : au minimum 3 actions avec objectifs chiffrés et responsables.
💡
Complétez toutes les cellules de votre onglet Excel avant de répondre aux questions. Les questions valident vos calculs.
